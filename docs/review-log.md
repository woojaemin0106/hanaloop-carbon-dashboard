## 2026-05-17 - PCF 계산 로직 구현

### 자동 검증

### 수기 검산

- 전기 활동량 합계: 1,029 kWh
  - 계산식: `1,029 x 0.456 = 469.224 kgCO2e`
- 원소재 플라스틱 1 활동량 합계: 3,186 kg
  - 계산식: `3,186 x 2.3 = 7,327.8 kgCO2e`
- 원소재 플라스틱 2 활동량 합계: 106 kg
  - 계산식: `106 x 3.2 = 339.2 kgCO2e`
- 운송 활동량 합계: 839 ton-km
  - 계산식: `839 x 3.5 = 2,936.5 kgCO2e`
- 총 배출량: `469.224 + 7,327.8 + 339.2 + 2,936.5 = 11,072.724 kgCO2e`
- Scope 2 총량: `469.224 kgCO2e`
- Scope 3 총량: `10,603.5 kgCO2e`
- 2025년 5월 중복 행 합산 결과: `2,210.076 kgCO2e`

### 구현 검토

- 배출계수는 활동 유형과 라벨이 모두 일치해야 매칭되도록 했다.
- 배출계수 `validFrom`이 활동일보다 늦으면 사용할 수 없도록 했다.
- `factorVersion` 옵션을 두어 특정 버전의 배출계수로 재계산할 수 있게 했다.
- 활동량이 음수이거나 생산수량이 0 이하이면 오류를 던지도록 했다.
- 월별 집계는 같은 월의 중복 행을 합산하도록 했다.
- Playwright 기본 테스트에서 dev 서버 자동 실행을 제거했다. Windows 환경에서 Next dev 서버가 종료되지 않아 테스트 명령이 타임아웃되었고, 현 단계의 검증 대상은 계산 로직이므로 서버 의존 없는 테스트로 분리했다.
- ESLint 설정은 Next 16의 flat config export를 직접 사용하도록 수정했다. 기존 `FlatCompat` 방식은 순환 구조 오류로 `npm run lint`가 실패했다.

### 다음 검토 포인트
